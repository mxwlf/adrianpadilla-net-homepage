# Accessibility rules

- Use semantic HTML elements (`<nav>`, `<main>`, `<article>`, `<section>`, `<header>`, `<footer>`) instead of generic `<div>` wrappers.
- ARIA attributes should only be used when semantic HTML cannot convey the intended role or state.
- All interactive elements must be keyboard accessible (focusable, operable, visible focus indicator).
- Focus order must follow a logical reading sequence; do not use positive `tabindex` values.
- Color contrast must meet WCAG AA minimums (4.5:1 for normal text, 3:1 for large text).
- Respect `prefers-reduced-motion`: disable or reduce animations when the user preference is set.
- All `<img>` elements must have meaningful `alt` text (or `alt=""` for decorative images).
- Form inputs must have associated `<label>` elements; error messages must be programmatically linked.
- Skip-to-content link must be the first focusable element on every page.
- Lighthouse accessibility score must remain >= 0.95.
